# Lumora v0.1.0 (early preview)

An early, incomplete preview. Not a full 1.0.

**Included**
- Full-screen standby clock (app-level; does not replace the lock screen or Always-On Display) with live time, date, battery level and charging status.
- 6 of the planned 40 clock themes: Minimal Digital, Neon Cyan, Flip Clock, Vertical Clock, Analog Classic, Minimal Analog. The other 34 are listed in the gallery as "Coming soon" and cannot be selected.
- Optional notification previews (off by default) via Android Notification access, with sender/text visibility, privacy mode, and 10/15/20/25/30 s auto-hide (default 15 s). Content is kept in memory only.
- Settings (12/24-hour, date format, date/battery visibility) persisted with DataStore.

**Not included yet**
- 34 themes, photo backgrounds, custom themes, charging automation, Rust integration (the Rust library exists but is not linked into the app), Compose/instrumented tests, onboarding and about screens.
