# Code of Conduct

Lumora is a small open-source project. We want it to be a friendly, respectful place to ask questions, report bugs and contribute.

## Our standards

Please:

- be kind and patient, especially with newcomers,
- assume good intent and give constructive, specific feedback,
- keep discussion about the work, not the person,
- respect others' privacy — never post other people's personal data or private message content.

Not acceptable: harassment, insults, discrimination, sexualised language or imagery, threats, doxxing, spam, or deliberately disruptive behaviour.

## Scope

This applies to issues, pull requests, discussions and any other project space.

## Enforcement

The maintainer may edit or remove comments, close or lock threads, and block people who break these rules. To report a problem, contact the maintainer, [@Aasimabdul](https://github.com/Aasimabdul), through GitHub (use a private security advisory if it must stay private).

This text is original and written in the spirit of the Contributor Covenant (<https://www.contributor-covenant.org>).
